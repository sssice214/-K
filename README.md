# 残月改版列车的K车私服分支小更新仓库

本仓库是 **StarRail Express 4.5.0** 的源码快照，用作「残月改版列车」的 **K 车私服分支**的小更新仓库。

| 项目 | 说明 |
| --- | --- |
| 上游项目 | StarRail Express（`io.wifi.starrailexpress`） |
| 基线版本 | 4.5.0，源码取自上游 `master`（提交 `30a01aef7`） |
| 用途 | 仅做小范围改动，不跟随上游全部更新 |
| 运行环境 | Minecraft 1.21.1 / Fabric Loader 0.19.3 / Java 21 |

## 构建

```bash
./gradlew build
```

产物位于 `build/libs/starrailexpress.jar`。
